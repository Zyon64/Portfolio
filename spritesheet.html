Z · actual game sprite sheet

This page documents the exact row order. To get the editable PNG itself, open the game and use Options → Download Sheet. It is generated from the same canvas functions used by the game, so it is not an approximate catalog.

Every cell is 48×48 px. Column 0 is the body. Columns 3–10 hold directional, live components where applicable (for example, the 8 hair directions of Mass, and Sentinel’s eye plus 8 rotating spikes). The code—not the PNG—keeps their position and movement. Keep the 576×1392 canvas dimensions and cell layout unchanged.
